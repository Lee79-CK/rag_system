# RAG Assistant 사용자 매뉴얼

> 대상: 사내 문서 기반 질의응답 챗봇 **RAG Assistant(Web Chat)** 를 사용하는 임직원
> 버전: v2.0 (2026-10) · 운영자용 문서는 [운영자 매뉴얼](operator-manual.md)

---

## 1. RAG Assistant 란

RAG Assistant 는 **관리자가 등록한 사내 문서에서 근거를 찾아 답하는 챗봇**입니다.

- 채널마다 **허용된 문서 범위 안에서만** 검색해 답합니다. 다른 채널의 문서나 대화는 보이지 않습니다.
- 답변 아래에 **참고한 문서와 위치(쪽)** 가 표로 함께 표시됩니다.
- 사내 폐쇄망에서만 동작하며 대화 내용은 외부로 나가지 않습니다. 인터넷 검색이나 일반 상식으로 답하지 않습니다.
- 근거가 되는 문서가 없으면 지어내지 않고 "제공된 문서에서 관련 근거를 찾지 못했습니다." 라고 답합니다.

## 2. 시작하기

### 2.1 접속 환경

| 항목 | 요구 사항 |
|---|---|
| 접속 주소 | 관리자가 안내한 주소 (랩 환경: `https://chat.rag.lab.local`) |
| 프로토콜 | **반드시 `https://`** 로 접속 — `http://` 로 접속하면 로그인 버튼이 동작하지 않습니다 |
| 브라우저 | 최신 Chrome / Edge / Firefox |
| 화면 | **PC 전용, 가로 1280px 이상** (모바일·태블릿 미지원) |
| 계정 | 관리자가 발급한 이메일 계정 (자가 회원가입·비밀번호 찾기 없음) |

> 처음 접속 시 "안전하지 않은 인증서" 경고가 나오면 사내 인증서가 PC 에 등록되지 않은 것입니다. 관리자에게 문의하세요.

### 2.2 로그인

1. 접속 주소로 이동하면 **로그인** 화면이 나옵니다.
2. **이메일 (계정 ID)** 과 **비밀번호** 를 입력하고 [로그인] 을 누릅니다.
3. 버튼이 "비밀번호 파생 중…" 으로 바뀌고 **몇 초** 걸립니다. 보안을 위해 비밀번호를 브라우저에서 암호화한 뒤 보내는 과정이며, 비밀번호 원문은 서버로 전송되지 않습니다.

로그인 상태는 브라우저를 닫았다 열어도 유지되며, 마지막 사용 후 **7일** 동안 사용하지 않으면 다시 로그인해야 합니다.

### 2.3 처음 로그인 — 임시 비밀번호 변경

관리자가 발급한 **임시 비밀번호**로 로그인하면 [내 정보] 화면으로 이동하고 "관리자가 발급한 임시 비밀번호로 로그인했습니다. 새 비밀번호로 변경해 주세요." 안내가 나옵니다. **바로 새 비밀번호로 변경하세요.**

### 2.4 비밀번호 변경

왼쪽 아이콘 줄의 **ME 내 정보** (또는 아래쪽 내 아바타 → **내 정보 · 비밀번호**) → **비밀번호 변경**

| 입력 | 설명 |
|---|---|
| 현재 비밀번호 | 지금 쓰는 비밀번호(또는 임시 비밀번호) |
| 새 비밀번호 | 아래 규칙 충족 |
| 새 비밀번호 확인 | 같은 값 한 번 더 |

**비밀번호 규칙**
- **12자 이상**
- 영문 대문자 · 소문자 · 숫자 · 특수문자 중 **3종류 이상**
- 이메일 ID, 표시 이름을 포함할 수 없음
- 현재 비밀번호와 달라야 함

> 변경하면 **이 브라우저를 포함한 모든 로그인이 해제**됩니다(다른 PC 포함). 화면이 로그인으로 돌아가면 새 비밀번호로 다시 로그인하세요.

### 2.5 로그아웃

왼쪽 아래 **내 아바타** → 이름·이메일·역할 확인 → **로그아웃**. 공용 PC 에서는 사용 후 반드시 로그아웃하세요.

## 3. 화면 구성

```
┌────┬──────────────┬──────────────────────────────┬──────────────┐
│ 레 │ 채널 목록      │ 채널 헤더 (# 이름 · RAG 상태)    │ 스레드 패널     │
│ 일 │ 채널 검색 ⌘K  │                              │ (답글 대화)    │
│    │ CHANNELS     │ 메시지 목록 (질문·답변)          │              │
│ CH │  # rag-…  3  │                              │              │
│ ME │  ⌂ ai-…      │ 입력창 (힌트 · 보내기)           │              │
│ 테마│              │                              │              │
│ 나 │              │                              │              │
└────┴──────────────┴──────────────────────────────┴──────────────┘
```

| 영역 | 설명 |
|---|---|
| **왼쪽 레일** | **CH 채팅**(빨간 숫자 = 전체 안 읽은 메시지 수), **ME 내 정보**, **DARK/LIGHT** 테마 전환, 맨 아래 내 아바타(로그아웃) |
| **채널 목록** | **내가 멤버인 채널만** 보입니다. `#` 공개, `⌂` 비공개 채널. 오른쪽 숫자는 안 읽은 메시지 수. 위쪽 검색창(**⌘K / Ctrl+K**)으로 채널 이름 필터 |
| **채널 헤더** | `# 채널명`, **RAG 상태 배지**, 표시 이름 · 멤버 수 · 대화 방식 · 채널 설명. 우측에서 스레드 표시 방식(A · 패널 / B · 오버레이) 선택 |
| **메시지 목록** | 날짜 구분선, 질문과 답변. 최근 **80개** 메시지까지 표시(이전 메시지 더보기 없음) |
| **입력창** | 이 채널에서 질문하는 방법을 알려주는 **힌트**가 위에 표시됩니다 |
| **스레드 패널** | 답변에 이어서 묻는 답글 대화. **챗봇 답변**에 마우스를 올려 [답글] 을 누르면 열립니다(내 질문에는 [답글] 버튼이 없습니다) |

**RAG 상태 배지**

| 배지 | 의미 |
|---|---|
| `RAG ON` | 이 채널의 **모든 메시지**에 챗봇이 답합니다 |
| `RAG · !rag` | **`!rag` 로 시작하는 메시지**에만 답합니다 (트리거 단어는 채널마다 다를 수 있음) |
| `RAG OFF` | 챗봇이 꺼져 있습니다. 일반 대화만 가능합니다 |

> 채널이 하나도 보이지 않으면 "참여 중인 채널이 없습니다. 관리자에게 채널 초대를 요청하세요." 가 표시됩니다. 채널 참여는 관리자만 할 수 있습니다.

## 4. 질문하기

### 4.1 채널 방식에 따라 다릅니다

입력창 위 힌트를 보면 이 채널의 방식을 알 수 있습니다.

| 힌트 | 질문 방법 | 예시 |
|---|---|---|
| "모든 메시지에 RAG 가 사내 문서 근거로 답합니다" | 그냥 질문을 입력 | `장애 등급별 대응 절차를 알려주세요.` |
| "!rag 로 시작하는 메시지에 RAG 가 답합니다" | **트리거 단어로 시작** (입력창 왼쪽 `!rag` 버튼을 누르면 자동 입력) | `!rag 연차휴가 이월 기준은?` |
| "RAG 응답 꺼짐 · 일반 대화만 게시됩니다" | 챗봇이 답하지 않습니다 | — |

트리거 단어 채널에서는:
- 트리거 단어로 시작하지 않는 메시지는 **일반 대화**로 게시되고 챗봇은 답하지 않습니다.
- 챗봇이 이미 답한 **스레드 안에서는** 트리거 단어 없이 이어서 질문할 수 있습니다("답글은 이어서 질문 · 새 질문은 !rag 로 시작").

#### LLM 직접 대화 (`/` 로 시작)

힌트 끝에 "**/ 로 시작하면 LLM 직접 대화(문서 검색 없음)**" 가 보이는 채널에서는, 메시지를 `/` 로 시작하면 사내 문서를 찾지 않고 LLM 이 일반 지식으로 바로 답합니다. 코딩·번역·문장 다듬기·요약처럼 사내 문서가 필요 없는 질문에 씁니다.

| 입력 | 처리 |
|---|---|
| `/파이썬에서 리스트를 역순으로 정렬하는 방법` | LLM 직접 대화 (`/` 는 빼고 전달) |
| `/위 답변을 영어로 번역해줘` | 이전 대화(채널 대화 맥락)를 이어서 LLM 직접 대화 |
| `연차휴가 이월 기준은?` | 기존처럼 사내 문서 근거 답변 |

- 직접 대화 답변은 배지가 **BOT · LLM** 이고, 출처 표 대신 "📎 사내 문서를 검색하지 않고 LLM 이 직접 답변했습니다. 사내 정보는 정확하지 않을 수 있습니다." 안내가 붙습니다.
- **사내 규정·수치·조직 정보는 `/` 없이 질문하세요.** 직접 대화는 문서를 보지 않으므로 사내 정보에는 모른다고 답하거나 틀릴 수 있습니다.
- 트리거 단어 채널에서도 `/` 로 시작하면 트리거 단어 없이 답합니다.
- 힌트에 안내가 없는 채널(관리자가 켜지 않은 채널)에서는 `/` 로 시작해도 일반 문서 근거 질문으로 처리됩니다.

### 4.2 입력 방법

- **Enter**: 보내기 · **Shift + Enter**: 줄바꿈
- 한 메시지 최대 **12,000자**
- 짧은 시간에 너무 많이 보내면 "요청이 많아 잠시 후 다시 시도해 주세요." 가 나옵니다(1인당 1분 10건 수준).

### 4.3 답변이 나오는 과정

1. 질문을 보내면 챗봇 메시지(**BOT · RAG**, `/` 직접 대화는 **BOT · LLM**)가 바로 생기고 깜빡이는 점이 표시됩니다.
2. "질문을 접수했습니다. 근거 문서를 찾는 중…" (또는 "생각 중…") 이 잠시 보입니다.
3. 답변이 **실시간으로 한 글자씩** 채워집니다.
4. 완료되면 **근거 문서 보기 (N건)** 버튼과 **피드백 버튼**이 나타납니다.

보통 수 초 ~ 수십 초가 걸립니다. 답변이 생성되는 동안 다른 채널로 이동해도 됩니다.

### 4.4 대화 맥락 (이전 대화를 기억하는 범위)

채널 헤더의 대화 방식 표시로 확인합니다.

| 표시 | 챗봇이 참고하는 이전 대화 | 답변 위치 |
|---|---|---|
| **채널 컨텍스트** | 채널 전체의 최근 대화 (**같은 채널의 다른 사람 질문도 포함**) | 채널 본문 |
| **스레드 컨텍스트** | 현재 스레드의 대화만 | 질문의 **스레드** (보내면 스레드 패널이 자동으로 열림) |
| **단발 질의** | 기억하지 않음 — 매 질문이 독립적 | 채널 본문 |

최근 몇 번의 질문·답변까지 기억할지는 관리자가 채널별로 설정합니다(기본 8회). 주제를 바꿀 때는 **새 질문(새 스레드)** 으로 시작하는 것이 정확합니다.

## 5. 답변 읽기

### 5.1 답변 구성

- 본문: 문서 내용을 근거로 한국어로 답하며, 핵심 문장 뒤에 **[1], [2]** 같은 출처 번호가 붙습니다.
- 채널 설정에 따라 답변 앞에 **@내 이름** 멘션이 붙을 수 있습니다.
- **출처 표** (답변 아래) — 기본으로 접혀 있습니다. **근거 문서 보기 (N건)** 을 누르면 펼쳐지고, 펼친 상태에서 **근거 문서 접기** 를 누르면 다시 숨겨집니다.

| 열 | 내용 |
|---|---|
| # | 본문의 [번호] 와 같은 번호. **답변이 실제로 인용한 문서만** 나오므로 번호가 1, 2, 3… 으로 이어지지 않을 수 있습니다(예: #2, #5) |
| 근거 문서 | 문서 제목 |
| 위치 | `p.11 · 섹션명` 형식의 쪽/섹션 (없으면 `-`) |
| 발췌 | 근거 문장 앞부분(최대 200자) |

> **중요한 업무 판단은 반드시 출처의 원문(해당 쪽)을 확인하세요.** 챗봇은 문서를 요약·재구성하므로 표현이 원문과 다를 수 있습니다.

### 5.2 근거를 찾지 못한 경우

"**제공된 문서에서 관련 근거를 찾지 못했습니다.**"(또는 비슷한 취지의 답변)와 함께 "문서 근거가 충분하지 않습니다. 질문을 구체화하거나 관련 문서 등록을 요청해 주세요." 안내가 나오고, **출처 표(근거 문서 보기 버튼)는 표시되지 않습니다.** 이것은 오류가 아니라 **이 채널에 해당 내용의 문서가 없다**는 뜻입니다.

- 질문을 더 구체적으로(문서에 나올 법한 용어로) 바꿔 보세요.
- 다른 채널에 있는 문서일 수 있습니다. 해당 채널에서 질문하세요.
- 필요한 문서라면 관리자에게 등록을 요청하세요.

### 5.3 오류 메시지

| 메시지 | 의미 / 조치 |
|---|---|
| ⚠️ 답변 생성 중 오류가 발생했습니다. 잠시 후 다시 시도해 주세요. | 일시적 서버 문제 또는 응답 시간 초과. 잠시 후 다시 질문하세요. 반복되면 관리자에게 채널명·시각을 알려주세요 |
| ⚠️ 이 채널의 RAG 응답이 비활성화되어 답변할 수 없습니다. | 질문 직후 관리자가 챗봇을 껐습니다 |

답변이 길면 끝부분이 잘릴 수 있습니다. 이 경우 "이어서 설명해 주세요" 처럼 후속 질문을 하거나 질문 범위를 좁히세요.

## 6. 피드백 보내기

답변이 끝나면 아래에 **👍 도움됨 N** / **👎 아쉬움 N** 버튼이 나옵니다(N = 전체 사용자 누적 수).

- 한 답변에 1인 1표이며, 다시 누르면 **마지막 선택으로 바뀝니다**.
- 👎 는 관리자가 **답변 품질을 개선하는 데 직접 활용**합니다(검색 설정 조정, 문서 보강, 평가 질문 추가). 틀리거나 근거가 엉뚱한 답변에는 꼭 👎 를 눌러 주세요.
- 이유를 적는 칸은 없습니다. 상세한 의견은 관리자에게 따로 전달해 주세요.
- 채널에 따라 피드백 버튼이 없을 수 있습니다.

## 7. 그 밖의 기능

| 기능 | 사용 방법 |
|---|---|
| 스레드(답글) | **챗봇 답변**에 마우스 → **답글** 로 이어서 질문. 질문 메시지에는 [답글] 이 없고, 답글에 다시 답글은 달 수 없습니다 |
| 링크 복사 | 메시지에 마우스 → **⋯ → 링크 복사** (해당 메시지로 바로 가는 주소) |
| 텍스트 복사 | 내 메시지에서 **⋯ → 텍스트 복사** (챗봇 답변은 마우스로 드래그해 복사) |
| 메시지 삭제 | 내 메시지에서 **⋯ → 삭제** (**확인 없이 즉시 삭제**, 챗봇 답변은 삭제 불가, 수정 기능 없음) |
| 채널 검색 | **⌘K / Ctrl+K** 후 채널 이름 입력 |
| 다크 모드 | 왼쪽 레일 **DARK / LIGHT** |
| 스레드 표시 방식 | 채널 헤더 **A · 패널**(오른쪽 패널) / **B · 오버레이** |

지원하지 않는 기능: 파일 첨부, 이모지 반응, 메시지 수정, 다이렉트 메시지, 알림, 메시지 내용 검색, 모바일 화면.

## 8. 좋은 질문 요령

| 이렇게 | 대신 |
|---|---|
| `안전사고 발생 시 과기정통부 보고 기한은?` | `보고 언제까지?` (대상이 불명확) |
| `P1 장애 대응 절차와 담당 조직을 알려주세요.` | `장애 어떻게 해?` |
| 문서에 나오는 **정식 용어** 사용 (예: "고영향 인공지능") | 사내 은어·약어만 사용 |
| 한 번에 한 주제 | 여러 질문을 한 메시지에 나열 |
| 주제가 바뀌면 새 질문/새 스레드 | 긴 대화에 계속 이어서 질문 |

## 9. 알아두어야 할 제한

- **채널 격리**: 챗봇은 그 채널에 허용된 문서만 검색합니다. 같은 질문도 채널에 따라 답이 다를 수 있습니다.
- **문서 기반 답변만**: 등록되지 않은 내용, 최신 뉴스, 일반 상식은 답하지 않습니다(관리자가 켠 채널에서는 `/` 직접 대화로 일반 질문 가능, §4.1). 문서가 갱신되기 전에는 이전 내용으로 답할 수 있습니다.
- **채널 컨텍스트 채널**에서는 다른 멤버의 이전 질문도 맥락에 포함됩니다. 개인적인 내용은 질문하지 마세요.
- 챗봇의 내부 추론 과정은 표시되지 않습니다.
- 입력한 질문·답변·피드백은 품질 개선과 감사를 위해 일정 기간 저장됩니다. **비밀번호, 개인정보, 비밀등급 정보를 입력하지 마세요.**

## 10. 자주 묻는 질문 · 문제 해결

| 증상 / 메시지 | 원인과 조치 |
|---|---|
| 로그인 버튼을 눌러도 반응이 없거나 "로그인에 실패했습니다." | `http://` 로 접속했거나 오래된 브라우저. **`https://`** 주소로 접속 |
| 이메일 또는 비밀번호가 올바르지 않습니다. | 입력 확인. 계속 실패하면 관리자에게 **비밀번호 재설정**(임시 비밀번호 발급) 요청 — 계정이 비활성화된 경우에도 같은 메시지 |
| 로그인 시도가 너무 많습니다. 잠시 후 다시 시도해 주세요. | 1분 후 다시 시도 |
| 요청이 만료되었습니다. 다시 시도해 주세요. | PC 시계가 5분 이상 틀림. 시간 자동 동기화 후 재시도 |
| 인증 설정이 완료되지 않았습니다. 관리자에게 문의하세요. | 서버 설정 문제 — 관리자 문의 |
| 세션이 만료되었습니다. 다시 로그인해 주세요. | 7일 이상 미사용 또는 비밀번호 변경 — 다시 로그인 |
| 채널이 하나도 없음 / 특정 채널이 안 보임 | 채널 멤버가 아님. 관리자에게 채널 초대 요청 |
| 채널을 찾을 수 없거나 접근 권한이 없습니다. | 멤버가 아닌 채널의 링크. 관리자에게 초대 요청 |
| 질문했는데 챗봇이 답하지 않음 | 트리거 단어 채널에서 `!rag` 없이 질문했거나, 배지가 `RAG OFF` |
| 답변이 실시간으로 안 나오고 새로고침해야 보임 | 네트워크 일시 끊김(자동 재연결됨). 계속되면 **F5** 새로고침 |
| 화면이 잘리거나 겹침 | 브라우저 창을 가로 1280px 이상으로 넓히기 |
| 답변 내용이 틀림 | 출처 원문 확인 후 **👎** — 관리자에게 채널명·시각·질문을 전달하면 빠르게 개선됩니다 |

**문의**: 계정·채널 초대·문서 등록 요청은 RAG Assistant 운영 담당자에게 연락하세요.
